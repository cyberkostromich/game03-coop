# Звериные королевства — прогресс

## Как запустить

```bash
python3 -m http.server 8000        # из корня репозитория
# открыть http://localhost:8000/game/index.html
```

Отладочные флаги в адресе: `?reveal` — снять туман войны, `?local` — сетевой кооп между вкладками одного браузера (BroadcastChannel) вместо WebRTC.

Сборка самодостаточной папки для любого статического хостинга: `python3 tools/web/bundle.py` → `build/web/`.

## Что сделано

**Ассеты (Blender, `tools/blender`)**: 23 юнита (4 фракции × рабочий/пехота/стрелок/элита, 4 героя, 3 крысы), анимации Idle/IdleSpecial/Walk/Attack/Hit/Death/Victory (+Work у рабочих, Cast у героев), запечённые «рисованные» текстуры, командный цвет. 19 зданий (ратуша, казарма, ферма, башня на фракцию; рудник, мельница, провал). Проверка взаимопроникновения деталей: `tools/blender/dev/clipcheck.py`.

**Симуляция (`game/src/sim`)**: детерминированный мир 20 Гц; навигация по полям потоков, строй и «прибытие группой»; бой по матрице урона и броне в формуле WC3; добыча золота (до 5 рабочих в руднике), дерева (деревья рубятся и открывают проходы), рыбы на отмелях; стройка с призраком размещения; найм с очередью до 5, точки сбора; улучшение ратуши T1→T3; 12 героев: опыт, уровни, навыки Q/W/E и ульт с 6-го уровня, 40 типов эффектов способностей из `data/heroes.json`; лагеря нейтралов с поводком и наградой; день и ночь (ночная охота котов, вой Бигля); Старая мельница даёт +10% золота тому, кто её держит; волны Крысиной Чумы из провалов, финальный босс — Крыса-Король; победа — уничтожить провалы или Короля, поражение — потерять все ратуши; «Королевская казна» и совместный ульт «Крестовый поход»; союзники под управлением компьютера.

**Клиент (`game/src/view`, `game/src/ui`)**: Three.js; рельеф из карты высот с рисованными тайлами, вода с пеной у берега, мосты, леса инстансами, туман войны во всех материалах; юниты — одна отрисовка на модель; снаряды по дуге, частицы, зоны заклинаний; HUD в духе WC3: ресурсы, апкип, часы дня и ночи, таймер волны, миникарта с туманом и сигналами, живой 3D-портрет, панель команд 4×3 с горячими клавишами и подсказками, сетка группы, очередь найма, сообщения; процедурный звук.

**Кооп (`game/src/net.js`)**: lockstep по ходам по 100 мс через WebRTC (PeerJS), хост ретранслирует команды; проверка хеша состояния и восстановление снапшотом при рассинхроне; лобби с кодом комнаты; отвалившегося игрока подхватывает компьютер.

## Управление

ЛКМ — выделить (рамка, Shift — добавить, двойной клик — все такие на экране) · ПКМ — умный приказ · A атака · M идти · S стоп · H стоять · P патруль · B строить · G добывать · C отнести груз · Q W E R способности героя · O изучить навык · Ctrl+1..9 отряды · F1–F3 герои · Пробел — к месту тревоги · Tab — подгруппа · Alt — полоски здоровья · Esc — отмена · F10 — меню · колесо — масштаб · края экрана, стрелки, средняя кнопка — камера.

## Тесты

```bash
node game/test/headless.mjs cats,dogs 6     # прогон экономики
node game/test/aimatch.mjs cats,dogs normal # матч ИИ до конца
node game/test/lockstep.mjs                 # детерминизм и восстановление снапшотом
node game/test/reach.mjs                    # проходимость карты
```

## Известные ограничения

- Внутри Artifact WebRTC запрещён: там доступна игра с союзниками-ИИ, сетевой кооп — в версии со своего сервера.
- Иконки способностей пока процедурные; отдельные иконки из Blender — следующий шаг.
- Нет предметов героев, флота, осадных машин и кавалерии из GDD.
