# Звериные королевства — план подъёма юнитов до уровня Warcraft III: Reforged

Текущая оценка первого прохода: **3–4 / 10**. Модели читаются, но выглядят как
надувные игрушки из примитивов. Ниже — разбор референсов, разрыв и план.

## 1. Что видно на референсах Reforged

Источник: официальная серия Blizzard «Tales from the Smithy» (Muradin, Arthas,
Jaina, Kael'thas, Mortar Team, Gryphon Rider, Sorceress); картинки лежат в
скретчпаде сессии, выводы ниже.

| Признак | Как у Blizzard | Как у нас сейчас |
| --- | --- | --- |
| Текстура | Ручная роспись: блики на кромках металла, тёмные стыки, потёртости, пряди шерсти и волос, швы кожи | Плоский цвет вершин + AO |
| Доспех | Твёрдые пластины с толщиной и фаской, **золотой кант на каждой кромке**, ярусные наплечники с загнутым краем, шипы, заклёпки, кольчуга под пластинами | Гладкие «пузыри» из lathe, без кромок |
| Командный цвет | Большие плоские панели (центр наплечника, табард, плащ) в рамке из канта | Мелкие пятна |
| Пропорции | Героические: широкие плечи, узкая талия, **огромные латные кисти и сапоги**, оружие размером с торс | Чиби: голова 40% роста, тонкие ручки |
| Контраст | Тёмный металл + яркое золото + насыщенный командный цвет (три больших цветовых блока) | Среднесерые тона, мало контраста |
| Лицо | Вылепленные надбровья, скулы, рот с характером | Шар с глазами |
| Силуэт | Каждый класс отличим сверху: рога, гребни, оружие, плащ | Все — шар на бочонке |

Из обсуждений Reforged: юнит должен быть отличим на поле (не делать всех
одинаково «тяжёлыми»); у пехоты лучше бригантина с заклёпками и саллет, чем
полный латный доспех; размер наплечников показывает статус юнита.

## 2. План

### Фаза A — технологии (пайплайн Blender)
1. **Запекание рисованной текстуры.** UV-развёртка каждого юнита в атлас
   1024–2048, затем запекание процедурного «рисованного» шейдера в diffuse:
   - кромки (Bevel-нормаль против истинной) → светлые блики на металле и коже;
   - полости (AO + вогнутость) → тёмные стыки;
   - вертикальный градиент света (верх светлее);
   - шум и мазки: пряди шерсти, потёртости и царапины металла, ткань;
   - сохранить отдельную маску командного цвета.
2. **Твёрдые доспехи.** Пластина = участок поверхности тела со смещением →
   Solidify (толщина) → Bevel (фаска) → **кант по границе** (труба вдоль
   граничной петли, золото/бронза). Ярусные наплечники с загнутым краем.
3. **Органика через Subdivision.** Низкополигональные «клетки» головы,
   морды, тела → Subsurf → применить. Детали формы: надбровья, скулы, щёки,
   пучки шерсти (щёки, грудь, локти, кончик хвоста).
4. **Нормал-мапы (опционально):** запекание детали с хай-поли
   (кольчуга, чеканка, шерсть).
5. Экспорт GLB с baseColor + metallicRoughness (+ normal), бюджет 6–12 тыс.
   треугольников на юнита, до 15 тыс. на героя (как в Reforged).

### Фаза B — арт-дирекшн
1. **Пропорции «героик-звери»** (Redwall / Armello): голова ≈ 27% роста,
   широкая грудь, узкая талия, крупные латные кисти с пальцами и когтями,
   массивные сапоги. Рост пехоты ≈ 1,15 м.
2. **Фракционные кит-доспехи по формуле Blizzard:** основной металл + кант +
   панели командного цвета.
   - Коты: воронёная сталь + серебро, бригантина с заклёпками, саллет с
     прорезями под уши, лёгкие и хищные силуэты.
   - Собаки: бронза + зелёная эмаль, тяжёлые ярусные латы, шипастые ошейники.
   - Хомяки: медь + терракота, «бочковые» латы, заклёпки, ремни, сумки.
   - Зайцы: позолота + клюквенный, чешуя и кольчуга, шишаки с чехлами для ушей.
   - Крысы: ржавчина + гнилой зелёный, латки из мусора, рваньё.
3. **Лица с характером:** злые веки, надбровья, клыки, шрамы у ветеранов.
4. **Оружие в 1,5–2 раза больше реального**, с кантом и гравировкой.

### Фаза C — цикл проверки
1. Рендер «как у референса»: тёмно-синий фон, 3/4 спереди, тот же свет;
   лист сравнения «референс | наш юнит».
2. Рубрика 1–10 по пунктам: силуэт, пропорции, доспех, текстура, лицо, цвет,
   читаемость с высоты RTS-камеры, анимация.
3. **Вертикальный срез:** довести одного юнита (Мечник-полосатик) до ≥ 7/10
   за несколько итераций, и только потом раскатывать технику на остальных.
4. Анимация: широкие дуги (у коротких рук замах над головой прячется в
   голове — замахи вбок/вверх), ключевые позы с выдержкой предзамаха,
   быстрый удар, пронос.
